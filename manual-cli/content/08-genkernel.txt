You must have realized that the kernel is NOT so up to date...

However, this is intentional.
After installation, you must update your kernel by compiling it yourself.

This is where genkernel comes in, this command automates the process of building a linux kernel from an
upstream official source (kernel.org), and then switches you to it automatically, so after a reboot, you'll
be on the latest official kernel.

Any kernels built by genkernel end with the "-gen" flag.

The genkernel help prompt is:

Usage: genkernel [--dry-run] [--jobs N]

To launch genkernel, type the "genkernel" command inside of your terminal,
or press ctrl + k inside thesh.

Launching genkernel, you will be greeted with this.

[INFO]  Genkernel: Custom kernels, made easy.

══ Fetching latest kernel versions
System running on kernel 6.18.10-gen

Available kernel versions:

  1) 7.3-rc6      (mainline)
  2) 7.2.9        (stable)
  3) 6.18.55      (longterm)
  4) 6.12.112     (longterm)
  5) 6.6.158      (longterm)
  6) 6.1.189      (longterm)
  7) 5.15.222     (longterm)
  8) 5.10.271     (longterm)

Select version to build [1]:

It is recommended to choose stable.

After choosing the kernel you want to use, it will ask you to either keep the config as it is
configure it with menuconfig, or use a tinyconfig (not recommend)

It will then download the kernel, compile it, and switch you to it.
When genkernel is done building, all you need to do is reboot, and your kernel will be up to date with all the
latest patches.

I can not compile

For people that do not wish to compile or have hardware they consider "too weak" for compilation, Haliade ships prebuilt binaries of the linux kernel, even though this kernel binary has less updates than the genkernel.

Note about genkernel

In Nvidia machines, a step of genkernel may fail (initramfs generation step), however, this is a false alarm, your kernel is installed, you are just not switched over to it, to make sure, write "chronos rewrite-limine" (see the Chronos and Generations section) in your terminal and reboot, you should be on the latest kernel afterwards, if not, please report an issue, as I am aware of it.
