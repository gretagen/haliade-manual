You now know everything there is to know about Haliade OS!

If you want to contribute to this project, it's documentation or components,
along with making it support more much software, please go on the GitHub at https://github.com/gretagen/HaliadeSYS/

If you want to ask questions, feel free to join the discord community of Haliade OS at https://discord.gg/SyFM6CcHKa

Or check out the official QnA:
https://github.com/gretagen/HaliadeSYS/wiki/QNA

All the links to the source code of Haliade's components are on the wiki's
Source code page, including ZETA, Nacelle, chronos, thesh, iniswap,
genkernel and zstrappa.

If you are experiencing issues or a confused about how Haliade OS works, please join the discord.

Thank you for using Haliade OS!
