This is the official Haliade OS manual.

The manual comes in two flavors:

-- manual-cli: a dependency-light TUI pager for the terminal, with its
   content in manual-cli/content/
-- manual-gui: a desktop entry that opens the HaliadeSYS wiki in your
   browser

Covering features such as :

-- How to acquire and install HaliadeOS                                                                                     
-- How to configure HaliadeOS declaratively                                                                     
-- Home management                                                                                              
-- How to configure thesh                                                                                       
-- How to use ZETA (the package manager)                                                                        
-- How to update your kernel                                                                                    
-- How to manage generations                                                                                    
-- Subspaces, and merging.                                                                                      
-- Init swapping                                                                                                
-- declarative plugins                                                                                          
-- How to write packages for ZETA                                                                               

This documentation is community effort, and everyone is welcome to contribute or correct mistakes 
done in the writing of this documentation.

(This documentation was written and read entirely by a HUMAN, the tui hoewever was built with some AI code.)
(The code of this manual is also documented by an AI.)

If you want to contribute to this documentation , please follow these rules :

-- No AI should be used to document the OS, please document what you know yourself.
-- AI can be used to expand the code of the manual. But only if you know what the code does yourself.

if anything is not covered in this manual,or has mistakes or is confusing please open up an issue.
Or contribute to the manual itself.

Thank you for reading.
