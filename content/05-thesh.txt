Thesh is the default shell of HaliadeOS, and an alternative to bash, zsh and fish.
This is the shell you have seen the second you have logged into the system, and (probably) the shell you are
currently using.

You can configure thesh by editing /etc/theshrc or ~/.theshrc
(read it's config by doing ctrl + e)

Thesh is made to be extremely customizable, but remains extremely lightweight.
Thesh can also have configured binds (like the average window manager) that can serve as quick keyboard shortcuts.

Thesh allows you to configure the following:

-- The prompt (default being "[-root | haliade-] /path $")
-- The colors
-- The opacity
-- The shortcut binds
-- The aliases
-- Typing animations
-- History limits

It also has some features such as:

-- allowing you to type commands in UPPERCASE
-- autocompletion / correction
-- command guessing

Learn more by checking the example file.

(By default thesh is paired with tmux to make your workflow faster and allow tiling. You can disable it by removing it's exec line in the thesh configuration file, or remove it if you do not want it)
