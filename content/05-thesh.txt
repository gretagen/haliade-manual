Thesh is the default shell of Haliade, and an alternative to bash, zsh and fish.
This is the shell you have seen the second you have logged into the system, and (probably) the shell you are
currently using.

You can configure thesh by editing /etc/theshrc or ~/.theshrc
(read it's config by doing ctrl + e)

Thesh is made to be extremely customizable, but remains extremely lightweight.
Thesh can also have configured binds (like the average window manager) that can serve as quick keyboard shortcuts.

Thesh allows you to configure the following:

-- The prompt (default being "[-root | haliade-] /path $")
-- The colors
-- The opacity
-- The shortcut binds
-- The aliases
-- Typing animations
-- History limits

It also has some features such as:

-- allowing you to type commands in UPPERCASE
-- autocompletion / correction
-- command guessing
-- terminal multiplexing.

Autocompletion allows TheSH to autocomplete the command when you press TAB from your history.
guesser is in it's name, it tries to "guess" the command you tried to type in case you mispell it, basically Thesh's version of autocorrect.

Thesh can also allow you to have terminal multiplexing (like on tmux, but easier to configure),
allowing you have multiple terminal sessions in one terminal or the TTY.
You can use it with these keybindings (configurable)

- alt + v to tile vertically
- alt + h to tile horizontally
- alt + arrowkeys to move.
