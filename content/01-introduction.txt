The HaliadeSYS (Or HaliadeOS) is a linux based operating system created by Gretagen.

It is a minimal,hbrid, reproducible, declarative and open source system made to be easy to adapt to and use.

This manual will show you the following:

-- How to install Haliade
-- How to configure Haliade declaratively
-- Home management
-- How to configure thesh
-- How to use ZETA (the package manager)
-- How to update your kernel
-- How to manage generations
-- Subspaces, and merging.
-- Init swapping
-- declarative plugins


It is recommended to read this manual as you install the system, as there is a lot to cover.
If you ever feel lost when using the system, don't hesitate to use the manual!
