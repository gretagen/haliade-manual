HaliadeOS is a linux based operating system created by Gretagen.

It is a minimal, reproducible, and open source system made to easy to adapt to, and is systemd free.

This manual will show you the following:

-- How to install HaliadeOS
-- How to configure HaliadeOS declaratively
-- Home management
-- How to configure thesh
-- How to use ZETA (the package manager)
-- How to update your kernel
-- How to manage generations
-- Subspaces, and merging.
-- Init swapping
-- declarative plugins


It is recommended to read this manual as you install the OS, as there is a lot to cover.
If you ever feel lost when using the OS, don't hesitate to use the manual!
